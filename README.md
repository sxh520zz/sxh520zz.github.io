# Xiaohan Shi — Academic Homepage

A responsive, static academic homepage for GitHub Pages.

## Preview locally
Open `index.html` in a browser. The page uses Google Fonts and otherwise has no build step or dependencies.

## Deploy to GitHub Pages
1. Upload the contents of this folder to the root of `sxh520zz/sxh520zz.github.io`.
2. Keep `index.html` at the repository root.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`.
5. Wait for the deployment to complete, then visit https://sxh520zz.github.io/.

## Customize
- Edit `index.html` for biography, affiliation, and publication records.
- Edit `assets/css/style.css` for visual styling.
- Edit `assets/js/main.js` for mobile navigation and publication filtering.
